# Sprint 16 · Staff copilot

**Goal:** a staff copilot in the panel that can read the records a role may already see, and can create or change CRM records only after the operator approves. The model key is an environment variable. There is no provider settings page.

## E2E scenarios

`COPILOT-01`, batch B21. Priority P2. Not run in this task.

## Don't

- Do not write bookings, payments, refunds, commissions, or documents from the copilot.
- Do not cancel a booking (OPS-007).
- Do not send passport, medical, dietary, accessibility, date of birth, or nationality to the model.
- Do not add an AI provider settings screen.
